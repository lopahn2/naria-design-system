# 설계 결정 기록

## 2026-11-14 인터뷰

사용자는 여러 상용 서비스를 취합한 샘플을 먼저 보고, 그중 마음에 드는 포인트를 선택한 다음 하나의 큰 디자인 시스템으로 통합하기를 원합니다. 정교한 UI와 고급 프론트엔드 엔지니어가 함께 고려한 듯한 UX를 지향합니다.

확정:

- React 19 + TypeScript.
- HTML에서 탐색하고 유지보수. CSS 토큰을 코드 원본으로 관리.
- 여러 서비스의 좋은 요소를 비교하는 단계가 최종 브랜드 선택보다 먼저.
- 특정 기업의 전체 화면을 복제하는 것이 아닌 naria-cloud만의 체계.
- Figma 의존성 없음.

현재 도구의 선택:

- 8개 영역 40개 비교용 샘플.
- 16개 참고 출처의 범위 표시.
- DesignBookmark 50개 진입점 검토 인덱스.
- 선택 보드·메모·검색·필터·JSON 입출력·라이트/다크·토큰 실험.
- 중요한 상호작용은 네이티브 HTML 의미를 우선 사용.

아직 확정하지 않은 항목:

1. 브랜드 색과 타이포그래피 밀도.
2. 둥근 정도와 표면·그림자의 사용 범위.
3. 모바일/데스크톱의 정보 밀도 차이.
4. 모션의 강도와 예외.
5. 최초로 실제 검증할 서비스와 대표 흐름.
6. 최종 컴포넌트 패키지의 배포 위치 및 버전 정책.

다음 인터뷰는 추상적인 취향 대신 샘플 ID와 구체적인 선택 이유로 진행합니다. 최종 시스템 제작은 사용자의 샘플 선택에 의존합니다.
