# 디자인 시스템 수정 및 검수 기록 · 2026-11-15

## 변경 결과

- **두 가지 색상 시안:** modern / playful. 각 시안에 blue, teal, green, yellow, orange, red 기준색 6개와 100·300·500·700·900 단계 제공.
- **공통 무채색 표면:** 팔레트는 canvas, surface, raised, subtle, text, border를 덮어쓰지 않는다. 입력창, 코드박스, 본문 카드와 안내 영역은 중립 표면을 사용한다. 색은 주요 행동, 선택, 포커스, 작은 배지·카테고리 포인트에 사용한다.
- **색상 문서:** 시안 선택, 공통 무채색 토큰, 색상 단계표, 실제 입력·코드·버튼·스위치 비교를 제공. 선택은 localStorage에 저장하고 중첩 Provider도 상속한다.
- **모션 갤러리:** #motion-lab을 Design System 라우트로 통합해 현재 사이드바와 헤더를 유지한다. 기존 82개 샘플, 검색, 선택과 페이지 이동을 보존한다.
- **ListRow:** trailing을 별도 flex 슬롯으로 감싸 Switch가 본문 너비를 빼앗던 문제를 수정했다.
- **Toast:** 설명이 없는 변형에서 아이콘·문구·행동·닫기를 수직 중앙에 정렬한다.
- **달력:** DatePicker는 직접 입력과 전용 Calendar를 연결하고 모바일에서는 responsive Dialog의 하단 시트를 사용한다. DateRangePicker는 선택 기간을 표시한다. Calendar는 오늘·선택일·기간, min/max 월 제한, 허용 범위 내 초기 진입점과 키보드 탐색을 제공한다.

## DatePicker 사용 변경

이전 `onChange(event)` 대신 `onValueChange(date)`를 사용한다. 값은 YYYY-MM-DD 문자열이다. DateRangePicker의 `onChange({start,end})`는 유지한다. 날짜 선택 후 달력을 닫고 트리거로 포커스를 되돌린다. min/max를 벗어난 직접 입력은 네이티브 폼 유효성 검사로 검증한다.

실제 브라우저에서는 ListRow 데스크톱, 시스템 내부 모션 갤러리, 행동 컴포넌트 8개를 확인했다. 화면 제어 연결이 중단된 후 사용자가 최신 로컬 HTML을 직접 확인하고 최종 팔레트 수정본의 GitHub push를 승인했다. 이번 변경에서 76개 전부의 데스크톱·모바일 시각 재검수, 실제 iOS/Android 및 스크린리더 검증을 완료했다고 주장하지 않는다.
