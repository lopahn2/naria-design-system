## 실제 브라우저 조작

- Combobox: `프론트` 검색 → 방향키 → Enter → `프론트엔드 개발` 선택, 목록 닫힘.
- Dialog: 열기, 제목으로 초기 포커스, Escape 닫기, 원래 열기 버튼으로 포커스 복귀.
- 가입 패턴: 빈 제출의 이름/이메일 오류, 입력 수정, 필수 동의만 선택, 완료 화면. 외부 계정 생성 없음.
- Tabs: 좌우 이동, End, 비활성 탭 건너뛰기, 처음으로 순환.
- DropdownMenu: 첫 항목 포커스, 방향키 이동, 비활성 항목 건너뛰기, Escape, 트리거 복귀.
- DataTable: 이름 오름차순, 현재 페이지 전체 4개 선택, 다음 페이지에서도 선택 개수 유지.
- HoldButton: 180ms 짧은 누름은 실행 안 됨, 1200ms 유지 시 확인 완료(기본 임계값 900ms).
- Calendar: 선택일에서 오른쪽 방향키 → 다음 날 포커스 → Enter로 선택.
- CommandPalette: 문서 검색으로 Button 문서 이동.
- 모바일 다크 Dialog: 너비 390px, 하단 위치 viewport 780px 끝에 정렬되는 시트 확인.
- 모션 감소: 표시 설정을 켰을 때 data-reduced=true, 버튼 transition-duration=0s 확인.
- 모바일 DataTable: 카드 목록 display=flex, 현재 페이지 4개 카드 확인.

## 수정한 항목

- 아이콘 버튼의 커스텀 속성이 DOM으로 흘러가지 않도록 분리.
- 입력 기본 경계를 별도 강한 경계 색으로 조정.
- SplitButton의 비활성 상태를 메뉴 트리거에도 연결.
- 명령 검색의 활성 옵션이 보이는 영역으로 따라오도록 처리.
- 삭제된 행의 선택 상태를 걸러 다음 선택과 표시에서 제외.
- 달력 외부 값 변경과 최소/최대 범위의 Tab 진입점 보완.
- 달력 PageUp/PageDown이 1월 31일→2월 말일처럼 월말을 보존하도록 보정.
- 시작일이 종료일보다 뒤로 바뀌면 종료일을 비워 재선택.
- uncontrolled Textarea의 글자 수도 입력에 따라 갱신.
- 모션 참조 번호를 실제 82개 목록과 대조.
- 예제 생성기의 따옴표 의존 제거와 불필요한 공통 상태 제거.

## 남아 있는 제품 검증

실기기 Safari/iOS/Android, VoiceOver/TalkBack/NVDA, 실제 200% 확대, 장문 다국어/RTL, 매우 큰 데이터, 네트워크 지연과 실제 API·인증·결제는 이번 범위에서 검증하지 않았습니다. 범용 UI 기반의 첫 버전이며 제품 전체에 대한 접근성 인증이나 장기 운영 검증으로 해석하지 않습니다.

정적 문서 번들은 오프라인 한국어 서체와 기존 모션 82개를 포함해 Vite의 큰 청크 경고가 있습니다. 실제 서비스에는 문서 전체 대신 1.2MB 압축 패키지를 사용하고, 필요 시 서비스에서 서체 서브셋/지연 로딩을 구성하세요. HTML 파일을 직접 여는 경우 clipboard/localStorage 정책은 브라우저마다 다릅니다.

## 재현

```sh
npm ci
npm run build
npm test
npm run test:examples
node scripts/system-qa.mjs
npm run preview -- --port 5173
```

`/system-check.html`은 초기 렌더 검사, `/responsive-check.html`은 폭·경로 선택 하네스입니다. QA 파일은 배포 산출물 ZIP의 정적 사이트에서는 제외했으며 스크립트로 재생성할 수 있습니다.
