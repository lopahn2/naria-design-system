# naria Design System 1.0 · 작업 범위

결과물: 웹 문서 + React/TypeScript 패키지. 실제 Figma 파일은 만들지 않는다(사용자 선택).

사용자 선호: Apple/IBM 버튼 위계, IBM 정보 밀도와 타이포, Toss/Adobe 입력, Apple 선택, Toss/Apple 탐색, 개선한 Toss/Apple 카드, Apple/Microsoft 피드백과 IBM 오류, Vercel/당근 모션. 보라색 제외. 공식 Radix 아이콘 사용. 중립 토대와 서비스별 의미 색상 분리.

## 포함

- Primitive → Semantic → Component 토큰, light/dark, 서비스 테마, 편안한/조밀한 밀도.
- 행동, 입력, 선택, 탐색, 표면, 오버레이, 피드백, 데이터 표시, 레이아웃의 재사용 컴포넌트.
- 컴포넌트별 실제 조작 데모, 변형·상태, props, 코드, 키보드·접근성 및 반응형 지침.
- 가입/설정/검색/데이터 관리/결제 요약/빈 상태 등 화면 조합.
- 기존 40개 탐색 샘플과 82개 모션 갤러리 유지.
- 패키지 빌드·타입 선언·토큰 JSON/CSS·오프라인 HTML·전체 소스.

## 검증

타입 검사, 논리/SSR 검사, 문서와 export 대응 검사, 브라우저 핵심 입력·키보드·모달·목록·상태 검사. 320/390/768/1440px 레이아웃 및 라이트/다크 점검. 검증하지 않은 실제 보조기술·실기기 결과는 완료로 표시하지 않는다.

## 경계

웹과 모바일웹의 범용 UI 체계가 범위다. 모든 산업별 특수 편집기/차트/지도/백엔드 기능을 포함한다는 뜻은 아니다. 결제·인증·파일 전송은 서비스가 연결할 API 계약으로 분리한다. 원본 모션 82개를 무조건 제품 컴포넌트에 넣지 않고 press/select/expand/enter/feedback/gesture 역할로 정리한다.
