# 구성요소 목록

## 행동

| 구성요소 | 역할 | 변형 |
| --- | --- | --- |
| Button | 명확한 위계와 짧은 눌림으로 다음 행동을 안내합니다. | Primary · Secondary · Outline · Ghost · Danger / S · M · L |
| IconButton | 공간이 제한된 곳에서 이름이 있는 단일 행동을 제공합니다. | Ghost · Outline · Primary / S · M · L |
| Link | 페이지나 외부 문서로 이동하는 목적지를 드러냅니다. | 내부 링크 · 새 창 링크 |
| ButtonGroup | 관련 행동을 같은 위계와 간격으로 묶습니다. | 수평 · 줄바꿈 / 주 행동 + 보조 행동 |
| SplitButton | 기본 행동과 대체 행동의 메뉴를 나란히 둡니다. | 기본 실행 · 메뉴 열림 · 비활성 |
| ToggleButton | 반복해서 켜고 끌 수 있는 상태를 유지합니다. | 선택 전 · 선택 후 · 비활성 |
| CopyButton | 클립보드 쓰기 결과를 실제 성공 여부에 맞게 알립니다. | 기본 · 복사됨 · 권한 실패 |
| HoldButton | 의도적인 확인이 필요한 행동에 진행률과 취소 여지를 줍니다. | 대기 · 누르는 중 · 중단 · 확인 완료 |

## 입력과 선택

| 구성요소 | 역할 | 변형 |
| --- | --- | --- |
| Field | 라벨·입력·도움말·오류의 순서를 일관되게 만듭니다. | 필수 · 선택 · 도움말 · 오류 |
| TextField | 읽기 쉬운 라벨과 즉각적인 오류 복구를 지원합니다. | 기본 · 아이콘 · 읽기 전용 · 오류 |
| Textarea | 긴 내용을 입력하고 길이 제한을 확인합니다. | 자동 줄바꿈 · 글자 수 · 크기 조절 |
| PasswordField | 입력한 내용을 안전하게 숨기고 필요할 때 확인합니다. | 숨김 · 표시 · 자동완성 · 오류 |
| SearchField | 검색어 입력과 지우기를 한 자리에서 제공합니다. | 비어 있음 · 입력됨 · 지우기 · 결과 없음 |
| NumberField | 정해진 범위와 단위 안에서 수량을 조절합니다. | 증가 · 감소 · 직접 입력 · 경계값 |
| Select | 정해진 목록에서 한 값을 네이티브 컨트롤로 고릅니다. | 플레이스홀더 · 선택됨 · 옵션 비활성 |
| Combobox | 긴 옵션 목록을 검색과 키보드로 빠르게 좁힙니다. | 닫힘 · 검색 · 선택 · 빈 결과 |
| MultiSelect | 검색 가능한 옵션과 선택 태그를 함께 제공합니다. | 닫힘 · 펼침 · 다중 선택 · 개별 해제 |
| Checkbox | 독립적인 항목의 선택과 부분 선택을 표현합니다. | 미선택 · 선택 · 일부 선택 · 비활성 |
| RadioGroup | 서로 배타적인 선택지를 한눈에 비교합니다. | 세로 · 가로 · 설명 포함 · 비활성 |
| Switch | 즉시 적용되는 설정을 켜고 끕니다. | Off · On · 설명 포함 · 비활성 |
| Slider | 연속적인 값과 양 끝의 범위를 함께 보여줍니다. | 기본 · 값 포맷 · 단계 · 비활성 |
| Rating | 네이티브 라디오 의미를 가진 1–5점 선택을 제공합니다. | 미선택 · 1–5점 · 비활성 |
| OtpInput | 자동완성과 붙여넣기가 가능한 숫자 인증 입력입니다. | 숫자 정리 · 최대 길이 · 오류 |
| FileUpload | 파일을 고르고 형식·크기를 검증한 뒤 제거합니다. | 비어 있음 · 드래그 · 파일 목록 · 거부 |
| DatePicker | 기기에서 익숙한 네이티브 날짜 선택을 제공합니다. | 기본 · 최소/최대 날짜 · 비활성 |
| DateRangePicker | 시작일과 종료일의 선후 관계를 유지합니다. | 시작 전 · 시작 선택 · 기간 선택 |
| TimePicker | 키보드와 모바일 시간 선택기를 모두 지원합니다. | 시간 · 분 · 간격 · 비활성 |
| ColorPicker | 네이티브 선택기와 HEX 값을 함께 보여줍니다. | 기본 · 선택됨 · 비활성 |
| Calendar | 월 탐색과 날짜 선택을 키보드 그리드로 제공합니다. | 오늘 · 선택일 · 다른 달 · 제한 날짜 |
| Agreement | 필수·선택 약관과 전체 동의 상태를 구분합니다. | 전체 · 부분 · 미선택 · 필수 오류 |

## 탐색

| 구성요소 | 역할 | 변형 |
| --- | --- | --- |
| Tabs | 같은 맥락의 콘텐츠를 한 영역에서 전환합니다. | Line · Pill · 옵션 비활성 |
| SegmentedControl | 서로 가까운 보기 방식 사이를 부드럽게 전환합니다. | 2–4개 옵션 · 선택 배경 · 비활성 |
| Breadcrumb | 현재 위치와 상위 계층으로 돌아가는 경로를 보여줍니다. | 2–5단계 · 현재 페이지 |
| Pagination | 전체 범위와 현재 위치를 유지하며 목록을 나눕니다. | 처음 · 중간 · 마지막 · 생략 표시 |
| Stepper | 완료·현재·예정 단계를 구별하고 이전 단계로 돌아갑니다. | 완료 · 현재 · 예정 |
| NavigationBar | 브랜드·주 메뉴·보조 행동의 순서를 정리합니다. | 기본 · 현재 위치 · 모바일 줄바꿈 |
| SideNavigation | 정보가 많은 서비스의 지속적인 탐색을 지원합니다. | 현재 위치 · 아이콘 · 배지 |
| BottomNavigation | 모바일의 핵심 목적지 3–5개를 손이 닿는 곳에 둡니다. | 현재 위치 · 아이콘과 라벨 · safe area |
| CommandPalette | 키보드로 페이지와 작업을 검색하고 실행합니다. | 닫힘 · 검색 · 방향키 탐색 · 빈 결과 |

## 표면과 콘텐츠

| 구성요소 | 역할 | 변형 |
| --- | --- | --- |
| Card | 제목·내용·행동을 일관된 경계로 묶습니다. | Outline · Filled · Elevated |
| ListRow | 정보 밀도를 유지하며 설명과 다음 행동을 연결합니다. | 정보형 · 이동형 · 앞/뒤 슬롯 |
| Accordion | 한 번에 필요한 정보만 펼쳐 읽도록 합니다. | 단일 열림 · 다중 열림 · 비활성 |
| Divider | 정보의 관계를 끊지 않으면서 영역을 구분합니다. | 수평 · 세로 · 라벨 |
| Avatar | 이미지 실패에도 이름으로 사용자를 구별합니다. | S · M · L / 이미지 · 이름 대체 |
| AvatarGroup | 참여자 일부와 나머지 인원수를 간결하게 보여줍니다. | 참여자 · 초과 인원 |
| Badge | 짧은 상태를 색과 텍스트로 동시에 전달합니다. | Neutral · Accent · Success · Warning · Danger · Info |
| Tag | 선택값이나 키워드를 작게 묶고 해제할 수 있게 합니다. | 정적 · 선택형 · 삭제형 |
| Tooltip | 포커스나 호버에서 보조 설명을 제공합니다. | 숨김 · 표시 · Escape 닫기 |
| ScrollArea | 문서 전체의 흐름을 유지하며 긴 내용을 제한합니다. | 세로 스크롤 · 키보드 포커스 |
| Carousel | 사용자가 직접 다음 콘텐츠를 넘겨 비교합니다. | 첫 장 · 중간 · 마지막 / 자동 재생 없음 |

## 레이어

| 구성요소 | 역할 | 변형 |
| --- | --- | --- |
| Dialog | 작업 맥락을 유지하면서 집중할 내용을 엽니다. | 데스크톱 중앙 · 모바일 시트 · 긴 내용 |
| AlertDialog | 되돌리기 어려운 행동의 결과를 먼저 설명합니다. | 취소 우선 · 확인 · 처리 중 |
| Drawer | 보조 작업과 상세 정보를 측면에서 제공합니다. | 열림 · 닫힘 · 스크롤 |
| BottomSheet | 모바일에서 짧은 선택과 보조 작업을 처리합니다. | 열림 · 긴 내용 · safe area |
| Popover | 현재 컨트롤 곁에 작은 설정과 설명을 펼칩니다. | Start · End / 열림 · 닫힘 |
| DropdownMenu | 추가 행동을 키보드로 탐색 가능한 메뉴에 모읍니다. | 기본 · 위험 행동 · 비활성 항목 |

## 상태와 피드백

| 구성요소 | 역할 | 변형 |
| --- | --- | --- |
| Alert | 문제·변화·성공과 다음 행동을 같은 위치에 설명합니다. | Info · Success · Warning · Danger |
| ToastProvider | 맥락을 방해하지 않고 작업 결과를 잠시 알립니다. | 자동 닫힘 · 포커스 정지 · 실행 취소 |
| Progress | 실제 완료 비율과 알 수 없는 대기를 구분합니다. | 결정형 · 비결정형 |
| Spinner | 짧은 대기 상태에 접근 가능한 이름을 제공합니다. | 크기 · 정지 대체 |
| Skeleton | 예상 레이아웃을 유지하며 콘텐츠 로딩을 알립니다. | 텍스트 · 사각형 · 원형 |
| EmptyState | 아직 없는 이유와 시작할 행동을 함께 안내합니다. | 첫 사용 · 검색 결과 없음 · 필터 결과 없음 |
| Result | 흐름의 완료나 실패를 명확하게 마무리합니다. | 성공 · 오류 · 경고 |
| Banner | 페이지 전체에 영향을 주는 정보를 눈에 띄게 둡니다. | 정보 · 주의 · 행동 링크 · 닫기 |
