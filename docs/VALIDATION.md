# 검증 기록

검증일: 2026-11-14 · v0.2 motion collection

## 빌드와 자동 검사

- React 19.3.0 / TypeScript 5.9.3 / Vite 7.3.1. 앱과 모션 소스 모두 TypeScript 검사 통과.
- Vite production build 및 단일 HTML 2종 생성 통과. 큰 청크 경고는 82개 오프라인 샘플 통합에 따른 알려진 크기 한계입니다.
- 테스트 6개 통과: 82개 ID와 원본 대응, HTML 50/React 32 분포, 모든 개별 HTML의 스크립트 구문·외부 스크립트/스타일 비의존·UTF-8·서체·출처 고지, 모션 선택 JSON 검증, 기존 선택 JSON 왕복/오류 거부, 대비 기준값.
- 기존 40개 디자인 샘플의 정적 렌더링 검사는 v0.1에서 수행했습니다. 이번 변경이 40개 모든 동작의 브라우저 재검사를 뜻하지 않습니다.

## 실제 브라우저에서 확인한 범위

- 로컬 정적 서버에서 앱 로딩 및 갤러리 검색/출처 필터/확대 확인.
- 82개 × 라이트·다크(모션 감소) = 164개 초기 렌더링 검사에서 0건 실패. 각 iframe의 ready 신호와 이후 400ms 동안 발생한 error/unhandledrejection을 수집했습니다. 장시간 실행·모든 인터랙션·시각적 정확성을 전수 검증한 것은 아닙니다.
- Kokonut Detent dial: 방향키로 21.0 → 21.5 값 전환.
- SmoothUI Siri orb: thinking → done 상태 전환.
- DesignBookmark Plan switch: 390px 앱 프레임 안에서 Monthly → Yearly 전환 및 선택 상태 확인.
- 선택 1개가 새로고침 후 복원됨. JSON 다운로드 → 선택 해제 → 다운로드한 파일 가져오기 → 선택 1개 복원 확인.
- 단일 HTML을 HTTP로 직접 열어 초기 경로가 모션 갤러리인지 확인.
- 390px iframe 안에서 모바일 레이아웃 육안 확인. 앱 문서 clientWidth와 scrollWidth가 모두 375px(스크롤바 포함 프레임 390px)로 가로 넘침 없음.
- 데스크톱 화면에서 갤러리와 확대창 시각 검사.

## 아직 검증하지 않은 범위

- 실제 iOS/Android, 모바일 가상 키보드·터치 제스처·safe area, 모든 브라우저의 file URL 실행/저장 정책.
- 82개 모든 동작의 키보드 지원, 모든 드래그 경로, 오랜 반복 실행 및 저사양 기기 성능.
- VoiceOver/TalkBack, 고대비 모드, 200% 글자 확대 및 전 상태 대비.
- ChatGPT 데스크톱/휴대폰 채팅 세션 동기화 문제. 앱 결과물 검증과 별개입니다.

본 기록의 모바일 검사는 데스크톱 브라우저 안의 좁은 iframe 검사이며 실제 휴대폰 검사를 대체하지 않습니다.
